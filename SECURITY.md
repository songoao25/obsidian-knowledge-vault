# Security policy

## Reporting security or privacy problems

Use a GitHub Issue for every report, including security and privacy reports.
Describe the impact and safe reproduction steps, but never include API keys,
passwords, personal notes, an exported Vault, logs containing note content, or
a proof of concept that exposes private data.

Maintainers will use the Issue to coordinate a safe fix. If a report cannot be
written safely without exposing private material, remove that material and
report only the behavior and environment version.

## Supported release

The currently supported public deployment package is v1.2.1 for macOS and
Windows.
