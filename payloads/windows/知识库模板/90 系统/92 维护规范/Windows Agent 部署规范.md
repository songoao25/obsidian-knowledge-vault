本规范只适用于由本项目提供的 Windows 通用部署包建立的独立 Vault。

Windows 部署副本由使用者自行选择并确认的本地 Agent 定时运行。首次部署时，Agent 必须先询问使用者模型优先顺序：ChatGPT 优先、DeepSeek 优先，或只启用其中一个；没有使用者确认不得设置或改变模型，也不得自行改用备用模型。Agent 也必须先说明它采用的实际定时机制。作业模板、这份规范以及同目录其他维护规范共同构成该副本的操作边界；发生冲突时，以更严格的保全和风险限制为准。

Agent 每次只处理 `00 收件箱` 中停止修改至少 10 分钟的资料。写入前必须确认目标不存在同名覆盖风险，并保留可恢复副本；失败时不得移动原始输入或留下半成品。它必须保全原始正文、URL、数字、条件、链接、媒体和明确引用的附件，不得编造来源或结论。

目录调整、正式笔记合并、重要删除、核心结论改变、10 篇以上批量变更、25% 以上行级改写、规则、模型或时间调整，以及对 `20 工作/29 SOP` 的任何正文写入，均须保持资料不动并请求本人明确决定。不得因同批、名称相近或主题相似合并资料。

Windows 副本的 Obsidian 插件负责补齐新建或移动 Markdown 的 `created`、`modified` 与目录默认标签；本人编辑后，Update modified date 插件在停止输入 10 秒后更新 `modified`。模板、维护记录和原始输入归档不因这项自动化产生伪修改时间。未知标签只报告，不得自行删除、合并或改写。
