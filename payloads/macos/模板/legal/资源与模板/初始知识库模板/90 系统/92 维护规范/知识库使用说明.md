日常只需要做两件事：把新内容放入 `00 收件箱`，阅读或修改已有笔记。需要高影响修改时，直接在对话中向使用的 Agent 说明要做什么，由 Agent 请求使用者确认。

AI 在本机时区、按部署时设定的时间每天自动整理（默认 08:00、11:00、14:00、17:00、20:00、23:00 六个时点；部署时可自定义每天整理次数与具体时间）。每次都会检查收件箱并把结果写入当天的“整理记录-AI”；当天首次运行时建立记录，最后一轮完成后再归档到 `90 系统/94 维护记录/94.1 整理记录`。任务重新加载时只做安装自检，不整理资料。高影响操作不写入整理记录，也不自动执行；它们只留在 `94.4 高影响操作记录`，等待使用者明确指令。

AI 不自动生成每日、每周、每月、季度或年度记录，也不另建 Markdown 运行日志。`40 记录`完全由使用者撰写；“生活、工作、学习”保存以后还会使用的知识、资料和方法。

`20 工作/29 SOP` 也完全由使用者撰写。等某个专题、典型案例话题或反复出现的工作问题积累了足够经验后，再由使用者亲自总结；AI 不会把资料自动放进去，也不会新建、移动、续写、改写或合并里面的笔记。系统仍可维护基础属性，并让这些 SOP 参与搜索和引用。

AI 会先判断输入是完整网页文章、你自己的长分析、零散碎片还是其他完整资料。网页和长分析默认保留原文，只清理重复整篇题头和错位的标题层级；只有高置信度碎片才会重新组织。无法判断时保留。

原始输入归档是 7 天回查副本。独立原文件直接放在日期目录，只有使用者批准的多文件资料包才建立文件夹；归档 Markdown 原页会显示一个未勾选的 `no_delete` 方框，只有使用者勾选后才不自动清理。其他归档从实际归档时间起满 7 天后自动定期清理并移入系统废纸篓；整理记录会明确说明这是到期归档原件的清理。

是否使用模型，以及哪些资料可以进入模型，在部署时选择并确认（模型密钥保存在本机钥匙串，不会写入知识库）。没有明确许可时，资料不得发送到外部服务。PDF、Word、图片、音频和视频能否提取内容，取决于本机可用的本地能力；无法可靠提取时原件留在收件箱。独立原文件直接放在日期目录，只有使用者批准的多文件资料包才建立文件夹。

在手机或桌面小组件新建“未命名”笔记时，空白笔记只会得到普通笔记和收件箱两个默认标签，不会因为暂时叫“未命名”而继承旧文章的主题或项目标签。要求 Agent 检查项目时，默认会连同真实笔记、插件、程序、配置、模板、任务、测试和说明一起完整审计。
