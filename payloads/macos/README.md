# 新知识库 · Obsidian 自动整理系统

> 把 Obsidian 变成「自动归档知识库」：资料丢进收件箱，到点自动整理、分类、归档。你只管记录，剩下的交给系统。

**当前版本：v1.1.0（macOS）**。Windows 版将作为独立项目另行发布，本仓库仅包含 macOS 版本。

---

## 快速开始（30 秒）

把下面这句话发给任意 AI 助手（Claude Code、Codex、DeepSeek 等）：

> 请把我这个 GitHub 项目部署到这台 Mac：`<本仓库地址>`。按项目里的部署指令一键配置，需要授权时我会授权一次，其余步骤请自动完成，最后验证部署结果。

助手会读取 `AGENTS.md`，自动完成安装、配置与验收。**部署期间你只需回答 3 个问题：**

1. **整理时间** —— 每天整理几次、分别在几点？（直接回车用默认 `08/11/14/17/20/23`；也可以说"每天 3 次，9 点 12 点 18 点"）
2. **整理模型** —— DeepSeek（推荐，只需一个 API Key）或 ChatGPT 桌面版（若已安装）
3. **模型密钥** —— 在这台 Mac 的终端隐藏输入一次（不要发到 AI 聊天中），随后安全写入 macOS 钥匙串

之后授权一次，其余全部自动完成，最后会真实验证模型可用性再报"部署成功"。

## 手动部署

```sh
git clone <本仓库地址>
cd <仓库目录>
python3 deploy.py                          # 交互式，按提示回答
# 已在钥匙串配置密钥时可非交互重装：
python3 deploy.py --yes --model deepseek --run-hours 8,12,18
```

## 核心特性

- **收件箱即入口**：文件、链接、图片、笔记丢进 `00 收件箱`，系统到点自动扫描、理解、分类、归档。
- **内容保全优先**：完整文章与资料默认原样保存，只有高置信度碎片才会被重新组织；不擅自合并、删除、改写你的结论。
- **定时可配置**：每天整理几次、几点，部署时说一句即可，之后随时可改。
- **模型可选**：DeepSeek / ChatGPT / 任意 OpenAI 兼容接口，部署时选定，密钥只存钥匙串。
- **诚实验收**：部署完成前真实调用一次模型验证可用性——模型不可用时部署明确失败，绝不出现"装好了但用不了"。

## 工作原理

```
收件箱 ──稳定 10 分钟──▶ 本地提取（OCR / PDF / 媒体）──▶ 模型给出分类方案（只读）
        ──▶ 本地事务写入 ──▶ 归档（7 天可回溯）
```

- 模型只接收资料、返回结构化建议，**无法直接操作文件**；写入由本地程序以事务方式完成，可回滚。
- 目录骨架以 `taxonomy.json` 为唯一权威，只创建缺失目录，**绝不覆盖已有内容**。
- 内置目录覆盖生活、学习和以法律服务为主的工作场景；不从事法律工作时，可在部署后按高影响变更流程调整 taxonomy。

## 安全与隐私

- 本仓库只含**可安全分发的通用框架**：无个人笔记、无密钥、无本机路径。仓库默认私有。
- 构建经过「源扫描 → 打包 → 发布件再扫描」三道脱敏门禁，CI 与提交钩子同样拦截。
- 发布包内的知识库维护规范为中性化版本：不含任何个人授权决定，模型使用范围由**每位使用者部署时自行确认**。
- API 密钥通过本机隐藏输入进入钥匙串，不接受命令行密钥参数，也不得粘贴进 AI 对话。

## 系统要求

- macOS（Apple Silicon 或 Intel），Python 3.11+
- 可选本地能力（缺失时自动降级并提示安装命令）：Spotlight、Vision OCR、poppler、ffmpeg、Whisper 等
